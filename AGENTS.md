# Aturan Kerja Summarevent

Repo ini dikerjakan Tim Summarevent untuk Bandung Build Challenge 2026: **Haikal** ([@HaikalFaruq](https://github.com/HaikalFaruq)) di frontend dan **Bintang** ([@bintangfabian](https://github.com/bintangfabian)) di backend, dibantu **Shelvia** ([@shelviapramodita](https://github.com/shelviapramodita)) di user testing & UX, **Awwal** ([@awwalakhalqin](https://github.com/awwalakhalqin)) di product & pitch, dan **Said** ([@imsaidm](https://github.com/imsaidm)) di system QA. Kami sering memakai AI agent. Aturan di bawah berlaku untuk semua orang dan untuk agent apa pun yang dipakai.

## 1. Tanpa atribusi AI

Commit, PR, issue, dan komentar tercatat atas nama orang yang menjalankannya. Jangan tulis atribusi AI dalam bentuk apa pun:

- Trailer seperti `Co-Authored-By: Claude <noreply@anthropic.com>`, `Claude-Session: …`, `Assisted-by: …`, dan trailer sejenis dari agent lain (Codex, Copilot, Cursor, Gemini, Aider, Devin, Jules, Amp, Warp, dan seterusnya).
- Footer seperti `🤖 Generated with Claude Code` atau `Generated by Copilot`, serta link sesi agent.
- Agent atau bot AI sebagai author atau committer. Commit selalu memakai identitas git kamu sendiri.

Kalau agent kamu menambahkan atribusi otomatis, matikan di setting-nya. Untuk Claude Code sudah dimatikan lewat `.claude/settings.json` di repo ini.

| Lapis | Yang dicek | Kapan |
| --- | --- | --- |
| `.githooks/commit-msg` | Pesan commit | Setiap `git commit` |
| `.githooks/pre-push` | Author, committer, dan pesan semua commit yang di-push | Setiap `git push` |
| Workflow `No AI attribution` | Sama seperti pre-push, plus judul dan deskripsi PR | Setiap PR dan push ke `main` |
| Branch protection `main` | Hanya menerima commit yang lolos cek `no-ai-attribution`. Force push dan hapus `main` diblokir | Di GitHub |

Hook aktif otomatis setelah `npm install` di `frontend/` (script `prepare`). Tanpa itu, aktifkan sekali per clone:

```sh
git config core.hooksPath .githooks
```

Kalau ditolak, perbaiki commit-nya. Jangan lewati hook dengan `--no-verify`, karena CI tetap menolaknya.

| Kasus | Perintah |
| --- | --- |
| Pesan commit terakhir | `git commit --amend`, lalu hapus atribusinya |
| Author commit terakhir | `git commit --amend --reset-author --no-edit` |
| Commit yang lebih lama | `git rebase -i origin/main`, tandai `reword` atau `edit`, lalu `git push --force-with-lease` ke branch fitur kamu, tidak pernah ke `main` |

Semua pola ada di `scripts/check-no-ai.sh` dan contohnya di `scripts/test-check-no-ai.sh`. Kalau ada agent baru yang lolos, tambahkan pola dan contohnya lewat PR.

## 2. Pembagian kerja

- **Frontend** (`frontend/`): Haikal. **Backend** (Convex, di akun Bintang): Bintang. Jangan mengerjakan bagian orang lain tanpa diminta. Butuh sesuatu dari sisi lain? Tulis kebutuhannya (endpoint, field, env) dan serahkan ke pemiliknya.
- Batas keduanya adalah kontrak API: [`docs/API-CONTRACT.md`](docs/API-CONTRACT.md) dan `frontend/src/api/contract.ts`. Mengubah kontrak berarti mengubah keduanya dalam satu PR yang disetujui frontend dan backend.
- Shelvia (user testing), Said (QA), dan Awwal (demo dan pitch) menguji dengan [`docs/PANDUAN-TES.md`](docs/PANDUAN-TES.md). Mengganti nama tombol, akun demo, atau data contoh yang disebut di sana berarti memperbarui panduan itu di PR yang sama.

## 3. Frontend

- Layar hanya bicara lewat `api` (`src/api/index.ts`), tidak pernah langsung ke storage atau `fetch`.
- Aturan bisnis yang murni ada di `src/domain/rules.ts`, alur per endpoint di `src/api/mock/adapter.ts`. Aturan baru masuk ke sana dulu, lengkap dengan unit test, baru dipakai layar.
- Satu kosakata status untuk semua layar: `src/domain/labels.ts`. Jangan menulis label status sendiri.
- Teks UI berbahasa Indonesia, tanpa bahasa daerah, supaya semua pengunjung paham. Tulis singkat dan langsung ke inti.
- Target sentuh minimal 44 px, status tidak dibedakan warna saja, dan tampilan dicek di HP 360 px sampai desktop.
- Tidak ada kode, aset, atau dependency yang tidak dipakai. `npx knip` di `frontend/` membantu menemukannya.

## 4. Sebelum commit

```sh
cd frontend
npm run typecheck && npm run lint && npm test
npm run e2e        # dengan `npm run dev` jalan di terminal lain, wajib kalau alur pengguna berubah
```

Pesan commit singkat dan menjelaskan perubahan, misalnya `feat: denah zoom ke baris kategori` atau `fix: harga tidak terpotong di HP 360 px`.
