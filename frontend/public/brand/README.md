# Brand assets

Logo final: konsep **C "Lorong"** (dipilih 3 Nov 2026). Dua blok kursi, hijau dan oranye, dipisah lorong
berbentuk S yang ujungnya membulat: jalan menuju kursimu, sekaligus huruf S untuk Summarevent.
Master, varian lengkap, papan pratinjau, dan skrip pembuatnya ada di `docs/brand/final/`.

Ikon web ada di `public/`: `favicon.svg` (ubin + potongan ukuran kecil dengan lorong lebih lebar),
`favicon.ico` (16/32/48), `apple-touch-icon.png` (180, kotak penuh, iOS yang membulatkan),
`icon-192.png`, `icon-512.png`, dan `maskable-512.png` (simbol di dalam zona aman 80% untuk ikon adaptif Android).

## Aturan pakai singkat
- **Ruang kosong**: minimal setinggi satu "lorong" (±14% tinggi simbol) di semua sisi.
- **Ukuran minimal**: simbol 16 px (pakai `favicon.svg`/potongan kecil di bawah 24 px), lockup horizontal tinggi 20 px.
- **Warna**: hijau `#006426`, oranye `#F26F22`, krem `#FFF6E6`, kuning `#FEDC01` hanya untuk aksen UI.
  Hijau, kuning, dan merah status di app tidak dipakai di logo.
- **Jangan**: memutar atau memiringkan simbol, menukar posisi warna blok, menambah bayangan/efek pada logo
  (gradasi hanya di ubin ikon app), meregangkan proporsi, atau menaruh lockup hijau di latar hijau.
- **Wordmark**: Plus Jakarta Sans (SIL OFL) weight 680 yang sudah diubah jadi path, jadi tidak butuh font terpasang.
